# ADR-0003：LoRA 手写实现，RLHF 只读 + 跑现成

- **状态**：已采纳
- **日期**：2026-10-22

## 背景

学习者已熟悉 LLM 应用层（agent、RAG、常见微调概念），本项目要补的是**机制**。现代轴（Stage 5–6）里：

- **LoRA**：轻量（几十行），直接串起 fine-tuning 机制，手写收益高、成本低。
- **RLHF**：pipeline 重（SFT + 奖励模型 + PPO/强化学习训练循环），手写投入大，且学习者已在应用层见过，边际价值低。

## 决策

- **LoRA**：Stage 5 手写实现并微调一个小模型。
- **RLHF**：只读论文 + 跑现成对齐模型对话，理解 SFT→奖励模型→PPO pipeline，不手写。
- **Stage 6（缩放定律 / MoE / 开源谱系）**：以读+跑为主。

## 后果

- ✅ 把有限的实现精力压在真正没学过的地方（Transformer / BERT / GPT 主线）。
- ⚠️ RLHF 只理解到「pipeline 长什么样」，不亲手训过——接受这个深度取舍。
- 未来若要深入对齐，可在 V2 补 RLHF 实现。
