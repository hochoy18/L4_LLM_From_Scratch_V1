# Stage 2c — BERT vs GPT-1 对比实验

- **对应论文**：复读 BERT + GPT-1
- **地位**：B1/B2 双分支的汇合点——把「同一个 Transformer 的两种装配」摊开对比。这是本项目的**核心洞察实验**。

## 目标

用同一套 `core/`，只换 **mask + head + 目标**，直观感受 encoder 与 decoder 的本质差异，以及它们各自擅长的任务。

## 实验设计

同一个 Transformer 骨架，三个变体：

| 变体 | 用哪半边 | 掩码 | 预训练目标 |
|---|---|---|---|
| BERT | encoder | 双向 MLM（随机遮 15%） | 猜被遮的词 |
| GPT-1 | decoder | 因果（只看左） | 猜下一个词 |
| 双向LM（对照组） | encoder | 无（双向全看） | 猜**每个**位置的下一个词 |

**值得亲手验证的"作弊"问题**：双向LM 若不加因果掩码，预测下一个词时等于偷看了答案——用实验展示它 loss 异常低/训练失效，引出因果掩码的必要性。

## 要观察的现象

- 同一个骨架下，encoder（双向）为何在**理解/分类**任务上强？
- decoder（单向）为何能做**生成**，但天生不擅长双向理解？
- 双向 vs 因果：训练目标对表征质量的影响。
